how a model reads.

a model never sees the text itself. it gets cut into pieces first, and every piece is just a number. this is lilstory's tokenizer, 8,000 pieces it learned from about 2 million kids stories.

words it saw a lot are one piece, anything else gets chopped up. duck is one token, tpu is t, p, u. my all lowercase headline costs 3 more tokens than the capitalised one, because the stories it learned from use proper capitals.

a neural net with no libraries.

no numpy, no pytorch, no mlx. every weight is a number in a python list, and backprop is written out by hand as loops. 784 pixels in, 32 hidden neurons, 10 outputs, about 25k weights. it gets 90.5% of the mnist test set right.

draw a digit, or show it a real one from the test set it never saw. its running the exact weights it learned.
