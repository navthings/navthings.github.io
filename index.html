what i work on.

pretraining llama style models from 8m to 523m params. the big ones are written in jax and trained on a kaggle tpu v5e-8, in 8.4 hour sessions that save and pick up where they left off. lilbase, sprout finetuning chat finetuning in mlx with the loss only on the assistant turns. lilchat went from 2.230 to 1.337 val loss in one night. lilchat research how much data a model actually needs. i trained the same model on four amounts of data and wrote it up as a paper. the paper evaluation every model goes through the same zero shot script, hellaswag, arc-easy and lambada, and gets compared against gpt-2. lilbase inference every model gets a 4 and 8 bit gguf, so they run in ollama and right here in the browser. playground

a 297m param llama style base model, pretrained from scratch in jax on a tpu v5e-8. it beats gpt-2 small on hellaswag and arc-easy, and loses on lambada.

sprout

the next base model. 523m params trained on 12 billion tokens from a four source mix, with the optimizer state sharded across 8 tpu chips. it finished on sep 27, loss 2.39 on held-out text.

the goalbeat gpt-2 xl, which is 1.5b params, or get close. then finetune it into a competitive coding model.
