tale: bedtime stories for my little brother
2026-09-12

my little brother kept asking me for bedtime stories, so i built something that could tell them.

tale is lilstory scaled up: about 50m parameters instead of 8m, 13 layers, still llama-style and still trained on tinystories on my mac. i also fixed a couple of things lilstory did badly. the learning rate now warms up, then eases off along a curve instead of staying fixed the whole time. and it gets exported to gguf, the format llama.cpp and ollama use, so it runs fast locally.

ollama run navthings/tale

the version that's up has only trained for 2,000 steps, so it's an early release. it writes simple tinystories-style text and still loses the thread sometimes. it's meant to stay small. it only needs to tell a short story.
